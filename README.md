# Color Palette AI

Website Streamlit untuk menghasilkan palet lima warna paling dominan dari sebuah
gambar menggunakan K-Means Clustering.

## Fitur

- Upload gambar JPG, PNG, atau WEBP.
- Ekstraksi lima warna dominan dengan K-Means.
- Tampilan palet warna, HEX, RGB, dan persentase dominansi.
- Color picker bawaan Streamlit untuk menyesuaikan hasil.
- Download hasil palet dalam format CSV.

## Menjalankan Aplikasi

```bash
pip install -r requirements.txt
streamlit run app.py
```

Setelah server berjalan, buka alamat lokal yang ditampilkan oleh Streamlit.
